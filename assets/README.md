# Assets

Drop art and audio into these folders. File names must match the names used in the story script;
the full list is in [`docs/ASSETS.md`](../docs/ASSETS.md).

```text
bg/                     backgrounds            e.g. bg/hara_kei_estate.png
sprites/<character>/    character sprites      e.g. sprites/helene/sad.png
cg/                     event pictures         e.g. cg/the_cup.png
chibi/                  word-game chibis       e.g. chibi/helene.png
music/                  music and ambience     e.g. music/japan.mp3
sfx/                    sound effects
ui/                     reserved for interface art
```
